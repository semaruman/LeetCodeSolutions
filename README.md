# LeetCode Solutions

Решения задач с [LeetCode](https://leetcode.com/) на C# (.NET 10).

## Структура

Каждая тема — отдельный проект, внутри папки `Easy` и `Medium`:

| Проект | Тема |
|--------|------|
| `LeetCodeArraySolutions` | Массивы |
| `LeetCodeBinarySearchSolutions` | Бинарный поиск |
| `LeetCodeHashTableSolutions` | Хеш-таблицы |
| `LeetCodeLinkedListSolutions` | Связные списки |
| `LeetCodePrefixSuffixSolutions` | Префиксы и суффиксы |
| `LeetCodeStackQueueSolutions` | Стек и очередь |
| `LeetCodeTwoPointersSolutions` | Два указателя |
